# 📊 Student Performance Analysis Dashboard

## 📌 Project Overview
The Student Performance Analysis Dashboard is a Power BI project designed to analyze student academic performance using marks, attendance, and assignment scores. It helps identify performance trends and compare results across departments.

## 🎯 Objectives
- Analyze students' academic performance.
- Calculate average marks and attendance.
- Track the overall pass percentage.
- Compare student performance across departments.
- Present key information through interactive visualizations.

## 🛠️ Tools and Technologies
- **Microsoft Power BI** – Dashboard creation and data visualization
- **Power Query** – Data preparation and transformation, if used
- **DAX** – Calculated columns and measures
- **CSV/Excel** – Dataset storage, depending on the source used

## 📂 Dataset
The dataset contains sample student information, including:
- Student ID and student name
- Department and gender
- Mathematics, Science, English, and Computer Science marks
- Attendance percentage
- Assignment score

## 📈 Key Performance Indicators (KPIs)
- **Total Students** – Number of unique students
- **Overall Average Marks** – Average marks across the four subjects
- **Average Attendance** – Average student attendance percentage
- **Pass Percentage** – Percentage of students whose average marks are at least 40

## 📊 Dashboard Visualizations
- KPI cards for important performance indicators
- Bar chart comparing average marks by department
- Donut chart showing students by department
- Scatter chart comparing attendance and assignment scores

## 💡 Key Insights
The dashboard can help users compare department performance, monitor attendance, and identify patterns in assignment scores and academic results.
